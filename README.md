# Azure Landing Zone (Terraform)

## 📌 Overview
This project demonstrates a secure Azure Landing Zone built using Terraform, following best practices for scalable and secure cloud architecture.

## 🧠 Architecture
- Hub-and-spoke network design
- Azure Virtual Network (VNet)
- Modular Terraform structure
- Environment-based deployments

## 🛠️ Technologies
- Terraform
- Microsoft Azure
- Infrastructure as Code (IaC)

## 🔐 Security Design
- Network segmentation
- Least privilege access principles
- Foundation for Zero Trust architecture

## 📂 Project Structure
- `modules/` → reusable Terraform modules
- `environments/` → dev and prod configurations
- root files → orchestration layer

## 🚀 Outcome
This project provides a scalable and secure foundation for deploying enterprise workloads in Azure.
